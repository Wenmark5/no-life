ONE-TIME SETUP

Connect a realtime lobby

The game is hosted on GitHub Pages. To turn on multiplayer, create a free Supabase project and add its Project URL and public anon/publishable key to online-config.js, then publish the updated files. Follow the online setup guide.

The lobby is public. Other online players can see your nickname, age, job, education, health, happiness, and recent journal moments. Don’t share private information. Chat is temporary and only available while players are online.
